# PNE Growth OS

Data utworzenia/aktualizacji: 2026-09-29
Status: wskaźnik do dokumentacji kanonicznej

PNE Growth OS jest planowaną, addytywną warstwą wewnątrz `adm.pnedu.pl`. Nie jest osobnym modułem publicznego portalu `pnedu.pl`.

Kanoniczna dokumentacja znajduje się w:

- [`pneadm/docs/pne-growth-os/README.md`](../../pneadm/docs/pne-growth-os/README.md)

`pnedu.pl` pozostaje publicznym serwisem, checkoutem i panelem uczestnika. Przyszłe zmiany w tym repozytorium mogą powstać wyłącznie dla jawnie zaakceptowanego przypadku użycia Growth OS i muszą zachować działanie portalu po wyłączeniu nowego modułu.

Na etapie dokumentacji v0.1 nie dodano tras, modeli, integracji, konfiguracji ani zmian zachowania `pnedu.pl`.
